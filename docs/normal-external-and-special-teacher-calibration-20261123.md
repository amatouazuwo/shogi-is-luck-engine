# 通常将棋での外部校正と特殊盤面での同一NNUE参考指し手検証 — 2026-11-23

## 目的と校正を分ける理由

特殊盤面（落とし穴・ブラックホール）を理解できない技巧2を、その盤面で直接戦わせることはしない。二つの独立した検証を行う。

1. **通常将棋のみ**：USI対応の技巧2（本物のv2.0.2）を外部比較相手として、rsshogi各ノード上限との指し手の相違と、実際の勝敗を測定する。
2. **特殊盤面のみ**：同じ障害物対応rsshogi NNUEの「1手6秒の高予算探索」を参考指し手として、ノード500・2000・10000・50000の各設定で同じ手を選ぶ割合を測定する。

どちらも**アマ級位を直接認定する仕組みではない**。人間と実際に指した勝率・棋力の把握などは今後必要。

**注意：**
- 先生役の1手6秒探索は最善保証でも正解手ラベルでもない。
- 複数の同等手があり得る。単なるトップ1の一致率は、正答率・悪手率・人間棋力とは異なる。
- 教師と生徒の評価値は探索時間が異なるため、その数値の差をそのまま「評価値損失」や「悪手」の量にしてはならない。
- ゲーム全体の特殊イベント1％効果・ブラウザ時間・通信切断は含まない。

## 今後の校正基準と注意

外部ソフトとの通常将棋での相対対戦結果は、アマ棋力認定ではない。相手の強さの公表基準・棋譜開始局面の多様性・先後交換・試合数・端末条件・時間設定を揃えて比較する。

**次の段階**は、通常将棋で外部ソフトの複数深さ設定とrsshogiの中間ノード値を、十分な対局数で比較し、加えて棋力の分かる人間プレイヤーの対局記録で相対評価を確認すること。特殊盤面は同一NNUEによる合法性・探索失敗・一手ミスの定義を拡張して別途評価する。

本工程ではゲーム本体の5難易度、通常「ふつう」の簡易CPU、ゲームPR#12のコード、`main/develop`、Render本番は**一切変更しない**。エンジンDraft PR#3の実験コードのみ。
