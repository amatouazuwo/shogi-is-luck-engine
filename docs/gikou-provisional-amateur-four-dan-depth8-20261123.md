# 技巧2 深さ8：「アマ四段程度（仮）」比較基準の採用（2026-11-23）

> **追加訂正（2026-11-23）**：公式技巧2のソースを再確認した結果、評価モデルの一部である`probability.bin`も必要でした（`src/main.cc`から呼ばれる`MoveProbability::Init()`が使用）。公式配布ZIPに同梱されていることと、SHA-256 `dc2b18f1eaa7551822901eab7b68c6f279cc449ef527462b611b5d9510cb6c1a` を[確認済み](https://github.com/amatouazuwo/shogi-is-luck-engine/actions/runs/45119493528)。これまでの技巧2戦は`params.bin`のみ、または`params.bin`＋`progress.bin`の不完全な条件だったため、**段級位・ノード数換算の決定根拠には採用しません**。3つの公式評価ファイルを揃え、既知の終局局面対策パッチを適用した[新しい再測定](https://github.com/amatouazuwo/shogi-is-luck-engine/actions/runs/45119596031)の結果を採用します。


## 採用する仮設定

**技巧2（Gikou2 v2.0.2）の探索深さ8を、開発用の「アマ四段程度（仮）」比較基準として使う。**

これは実測段位や技巧2開発元が保証する四段ではなく、**ユーザー指定の便宜的な呼称**である。人間プレイヤーとの対局は要求せず、厳密な段位換算は本工程の目的としない。

| フィールド | 値 |
|---|---|
| 参照エンジン | 技巧2（本物のGikou 2 v2.0.2、公式配布評価パラメータ） |
| 比較用探索深さ | **8** |
| 開発用の表示 | **アマ四段程度（仮）** |
| 位置づけ | 自動対局に使う外部参考ソフトの暫定棋力目安 |
| 四段実測済み | **いいえ** |
| 人間との対局 | **省略** |
| ゲーム側の正式難易度 | **変更しない** |

設定を`benchmarks/strength/ci/gikou-reference-proxies.mjs`として記録した。深さ8を使うときのみ比較レポートへラベルが付く。アマ段級位認定を意味するフラグは常に`false`。

## 自動検証での使用

`external-usi-depth-grid-match.mjs`は実技巧2を`DepthLimit=8`と`go depth 8`で動かせる。 `external-usi-depth-grid-scorecard.mjs`は深さ8とラベルの一致を独立検査する。他の探索深さ2～5に四段ラベルを付ける変更は認めない。単体テストも追加。

`.github/workflows/gikou-depth-grid-calibration.yml`には**深さ8の仮ラベルに関する単体テスト**を追加した。2026-11-23の試験的な実技巧2深さ8の対局起動（10,000ノードrsshogi、局面ID8/9）は、技巧2側が対局途中で終了し、Node.jsの終了処理にEPIPEが発生して**4局の検証は成立しなかった**。原因は未特定。この失敗を勝敗や棋力の根拠に使わず、深さ8の実対局は必須CIから外した。仮ラベルとして使う設定は維持する。

## 実用上の注意

人間の段位の検証は**今後も必須工程にはしない**。開発上は「技巧2・深さ8を仮四段の目安」として扱ってCPU強さの相対比較を続ける。

ただし、技巧2の深さ8には自動的に1秒の思考時間上限がかからないため、rsshogiのノード＋1秒制限と同じ思考条件ではない。実際の特殊盤面では技巧2に障害物ルールの理解がないため対局相手として使わず、同一rsshogi同士の強弱検証を維持する。

エンジンDraft PR #3のみ変更。ゲームPR #12、既存「ふつう」簡易CPU、正式な難易度、`main/develop`、Render本番は一切変更しない。

## 継続工程での修正結果（2026-11-23）

当初の技巧2深さ8が118手目で終了する問題は、**終局局面で合法手ゼロにもかかわらず実現確率を計算する、技巧2側の探索処理**が原因と判明した。公式v2.0.2の`src/movepick.cc`に、合法手0件なら確率計算を行わない最小限のガードを検証用に適用した。また、以前の対局環境で欠落していた公式`progress.bin`を`params.bin`とともに使用するよう修正した。

- [修正した深さ8での再現局面単独検査：成功](https://github.com/amatouazuwo/shogi-is-luck-engine/actions/runs/45118620237)。詰み局面で`B*2a`を返した。
- [修正した深さ8 vs rsshogi10,000ノード：4局完走・監査成功](https://github.com/amatouazuwo/shogi-is-luck-engine/actions/runs/45118765575)。**rsshogi2勝・技巧2勝**。これは四段認定を意味しない。
- [不足していた進行度評価ファイルを補った全対局再測定](https://github.com/amatouazuwo/shogi-is-luck-engine/actions/runs/45118969180)。従来の深さ2～5の実験数値は、進行度評価ファイルが欠落していた条件の参考記録にすぎないため、修正後の比較値と混同しない。

比較に使う技巧2は、**「公式ソース＋終局ガード1件の検証用パッチ」**であり、公式が配布したバイナリそのものではないことを明記する。ユーザー指定の「深さ8＝アマ四段程度（仮）」という便宜的基準と、対人段級位検証を要求しない方針は変更しない。ゲーム難易度や本番環境にも変更なし。
