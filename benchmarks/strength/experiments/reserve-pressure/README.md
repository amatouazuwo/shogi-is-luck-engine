# 穴による持ち駒の王手経路の補正

現行穴対応SDKのソース基点 `ae8d8effdb04b6b0e9f1a73a03cfafbd41843e67` と、同じ v0.4.0 の内蔵NNUEを使う評価実験。持ち駒から王手をかけられる升に絞る。盤上の飛び駒と玉の逃げ道の評価は既存の実験に記録している。 [従来の補正](../hole-eval/)

## 補正

各玉を起点に、相手が実際に持つ香・桂・銀・金・角・飛の王手を逆算する。同じ駒配置・持ち駒で穴のない状態と、穴のある状態を比べる。飛び駒の線上では穴とその先の升を取り除く。駒のいる升は両方から除く。香と桂は玉から逆向きに求める構造上、前に進めない段は候補に入らない。

持ち駒の種類ごとに候補数0・1・2・3・4以上の効用を0・3・5・6・7とし、飛角と銀を4、金と桂を5、香を3倍する。これは利きと選択肢の概算で、特定の棋譜や戦術問題による最適化はしていない。同種の駒を2枚以上持つ場合も即時の候補は重複して数えない。手番側と相手側の失った効用の差を既存の静的評価に加え、補正全体を±80に抑える。穴のない局面および素材評価器では従来経路を通る。

補正が数えるのは王手の幾何学的な候補。自玉への王手、打った駒の即時捕獲、成り、打ち歩詰めの読みは探索と合法手生成に委ねる。二歩と打ち歩詰めで特殊な制約がある歩の打ち場所は補正に含めない。局面によっては修正値が小さく、棋力の差が出ない可能性がある。

## 実装確認

- Rust 1.95.0 の単体試験3件に成功。飛車の線の遮断、白黒反転・手番反転、桂の向き、既存駒の奥にある穴、持ち駒なし、穴なしを確認した。
- wasm32-unknown-unknown の実SDKを作成。穴1・9の実WASMとWorkerのスモークを通し、SDKの全ファイルをSHA-256で照合した。基準SDKのWorker・MIT・依存通知を同じバイト列で使う。
- 既存100局面に対して基準と全合法手集合が一致し、計2,749手。静的評価値が変わったのは8局面、最大絶対値は8。通常8局面×固定1,000・5,000ノードの16件で着手、評価値、深さ、ノード、読み筋がすべて一致した。棋力の採用判断は未使用の戦術と先後入替対局を待つ。 [固定対照ログ](fixed-control.jsonl)

## 再現方法

Rust 1.95.0とWASMターゲット、Python 3.11以降、Node 22を使用する。ビルドは固定上流、既存穴対応パッチ、公式ZIPに内蔵されたモデル、ここで追加したソースの順に適用する。実計測に使ったSDKのハッシュと依存の情報は [マニフェスト](manifest.json) と [SHA-256](SHA256SUMS) にある。実計測SDKは固定上流をローカルのアーカイブから展開してビルドし、現行SDKのWASM以外の実ファイルを再利用してパッケージ化した。Rustの最適化出力はビルドパス等により差が生じ得るため、対局ログに使用した各SDKのハッシュを記録する。

```sh
RUN_ENGINE_TESTS=1 ./build-reserve-pressure-sdk.sh /path/to/shogi-is-luck-engine /tmp/reserve-sdk
node fixed-control.mjs /path/to/baseline-sdk /tmp/reserve-sdk \
  ../../tactics/corpus.jsonl ../normal-continuous/match-stock-100-second-holdout.jsonl
```

未使用局面による評価は `forensics/heldout/run-heldout.mjs` で同じモデル・現行穴対応SDKと比較する。勝敗を測る場合は、使っていない開始局面の組ごとに先後を入れ替え、手数上限で止まった局を分けて記録する。

### 実戦形式の対照用開始局面

候補の採点と別に先後入替用の開始8局面を固定した。穴の種類ごとに序盤・中盤・駒数の少ない局面を含み、左右反転・先後反転を含め既存の特殊局面台帳と重複していない。生成シード4個を穴の種類間で共有するため、8局面を完全に独立な標本とは扱わない。 [固定した開始局面](direct-openings.jsonl)

```bash
node ../../obstacle-matches.mjs --game-root "$GAME_REPO" --candidate-sdk /tmp/reserve-pressure-sdk \
  --reference /path/to/obstacle-reference --opponent baseline --holdout --offset 30 --pairs 4 \
  --kind both --budgets 100 --ply-cap 100 > /tmp/reserve-pressure-direct-100.jsonl
```
