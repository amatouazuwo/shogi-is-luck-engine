# 中盤・終盤を起点とする追加対局

`fixtures.jsonl` はタイム制限付きエンジンで採点する前に固定した4つの盤面。凍結したゲーム本体の合法手判定で、各SFENの初期局面から記録された全USI手順を再生する。最終SFENと合法手集合が記録と一致したときに対局を始める。各開始局面で先後を入れ替え、持ち時間3分を開始局面から計時する。開始前の手順は定跡や盤面の由来として使用し、対局の反復履歴と計時は開始局面から記録する。開始局面から60手で未決着として打ち切る。

| CPU設定 | 2つの開始局面 | 予定局数 |
|---|---|---:|
| 500ms | #200 中盤・平手由来、#203 終盤・ランダム由来 | 4 |
| 1500ms | #201 中盤・ランダム由来、#202 終盤・平手由来 | 4 |

`openings.jsonl` の予算が実行割り当て。`fixtures.jsonl` にある予算は元の候補一覧の項目で、局面と合法手の監査用。メインの追加対局とは異なる開始局面・手数上限なので、集計は別に保存する。

```bash
bash run-supplemental.sh "$NORMAL_SDK" ../frozen-game 2
node summarize.mjs
```

ゲームソースとSDK、実測時間、Worker CPU時間の定義は親ディレクトリの追加対局と同じ。
